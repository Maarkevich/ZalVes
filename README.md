# ZalVes

Оффлайн PWA-дневник тренировок для Android и iOS.

## Структура

Все файлы лежат в корне репозитория, без папок:

```text
index.html
styles.css
app.js
exercise-catalog.js
sw.js
manifest.webmanifest
icon-192.png
icon-512.png
exercise-01.png … exercise-13.png
```

Добавьте свои `icon-192.png` и `icon-512.png` в корень. Они используются в PWA, favicon и превью ссылок. Для соцсетей GitHub Pages может показывать OG-превью после первого индексирования страницы.

## Публикация GitHub Pages

1. Скопируйте содержимое этой папки в репозиторий `Maarkevich/ZalVes`.
2. В **Settings → Pages** выберите **Deploy from a branch**, ветку `main`, папку `/ (root)`.
3. Адрес: `https://maarkevich.github.io/ZalVes/`.

## Обновления без поломки данных

Версия приложения находится в `app.js` (`APP_VERSION`) и в `sw.js` (`VERSION`). Текущая версия: `1.2.1`. При каждом релизе меняйте `APP_VERSION` в `app.js` и `VERSION` в `sw.js`, например `1.2.1` → `1.2.2`. После установки баннер скрывается автоматически: приложение проверяет standalone-режим и сохраняет состояние установки.

## Каталог упражнений

Каталог описан в `exercise-catalog.js`. Изображения должны лежать рядом с остальными файлами и называться `exercise-01.png` … `exercise-13.png`. В форме тренировки кнопка **«Выбрать упражнение»** открывает каталог. **«Выбрать»** подставляет название и отдельные группы мышц в поля, **«Открыть»** показывает крупное изображение с кнопками масштаба и поддержкой жеста pinch/перетаскивания. Группы мышц сохраняются массивом `muscles`, а в старых записях автоматически разделяются по запятым вне скобок. Service Worker сначала скачивает новый набор файлов, а затем удаляет старый кэш. Данные хранятся отдельно в `localStorage` и автоматически мигрируют со старого ключа `zalves-data-v1`.

Рекомендуемый порядок: изменить версию → проверить приложение → закоммитить все файлы одним коммитом. Не меняйте ключ хранилища без миграции.

## Возможности

- полноценная работа без интернета после первого открытия;
- установка с баннером на Android и подсказкой для Safari/iOS;
- безопасное версионирование и очистка старых кэшей;
- редактирование и удаление тренировок;
- автотеги групп мышц и упражнений через datalist;
- статистика тренировок, подходов, лучшего веса и общего объёма;
- графики веса тела, замеров и силовых показателей;
- экспорт резервной копии JSON;
- iOS safe-area, запрет масштабирования и увеличения формы при вводе;
- OG/Twitter метаданные с иконкой приложения.

На iOS: Safari → **Поделиться → На экран «Домой»**. Для проверки полного офлайна откройте приложение один раз онлайн, затем включите авиарежим и перезапустите его.
